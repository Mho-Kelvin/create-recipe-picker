# Create Recipe Picker

A Forge 1.20.1 mod that resolves [Create](https://www.curseforge.com/minecraft/mc-mods/create) recipe conflicts via an in-game GUI. When two or more recipes match the same input, you pick which one wins.

## Requirements

- Minecraft 1.20.1
- Forge 47.x
- Create 6.0.x

## Usage

Drop the jar in your `mods/` folder. In-game: `/createrecipepicker`.
